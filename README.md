# Analyzing Warehouse Stock Based on Real Price List Data

Анализ данных прайс-листа электронных компонентов для выявления структуры ассортимента и ключевых торговых метрик.

##  Описание проекта

Проект анализирует реальный прайс-лист электронных компонентов (10,748 позиций) для:
- Понимания распределения цен
- Классификации товаров по ценовым категориям
- Выявления самых дорогих позиций
- Определения общей стоимости склада

## База данныйх
Ссылка на базу данных: https://drive.google.com/file/d/1-FKfQ0hPuw0chYofywaj_MbA2uQ-iwqJ/view?usp=sharing

##  Используемые инструменты

- **Python 3** — основной язык
- **Pandas** — обработка и анализ данных
- **Git & GitHub** — управление версиями
